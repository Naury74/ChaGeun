# 홈 날씨 지역 목록 (시·도 → 시·군·구 → 읍·면·동)

홈 날씨에서 "지역 직접 고르기"로 고르는 전국 행정구역과 대표 좌표다. 앱 안에
`data/weather/src/main/assets/weather/korea_regions.csv`로 들어 있고, 네트워크 없이 읽는다.

## 바꾼 것

`scripts/build-korea-regions.py`로 만든다(openpyxl 필요).

- 칸: `행정구역코드, 그 단계 이름, 위도, 경도[, 시·도 짧은 이름]`. 원본의 경도·위도(초/100)를 소수 넷째 자리(약 10m)로 줄였다.
- 이름은 원본 그대로 둔다(`수원시장안구`). 앱이 화면에 쓸 때 `수원시 장안구`로 띄어 쓴다.
- 시·도 짧은 이름(서울특별시 → 서울, 전남광주통합특별시 → 전남광주)은 스크립트의 표에서 붙인다.
- 좌표가 0인 이어도(해양과학기지) 두 줄은 뺐다.
- 격자 X·Y, 위치 업데이트 날짜 칸은 쓰지 않아 뺐다.

결과: 3,836곳(시·도 16, 시·군·구 256, 읍·면·동 3,564), 약 146KB. APK 안에서는 압축되어 약 58KB(59,272바이트)다.

## 앱에서 쓰는 방법

- 설정(DataStore)에는 고른 지역의 행정구역코드만 저장한다. 좌표는 저장하지 않는다.
- 날씨를 받을 때 고른 지역의 대표 좌표를 소수 둘째 자리(약 1km)로 반올림해 MET Norway에 보낸다.
  기기 위치("현재 위치")는 계속 소수 첫째 자리(약 10km)로 반올림한다. `docs/release/data-safety.md` 참고.
- 예전 버전이 저장한 시·도 이름(`Busan`)은 `WeatherRegionMigration`이 코드로 바꾼다. 2026-07 원본에서
  광주광역시와 전라남도가 전남광주통합특별시로 합쳐져, 광주는 예전 대표 지점(시청)이 있는 `전남광주 서구`로,
  전남은 `전남광주`(무안 도청 지점)로 옮긴다.
- 원본을 새 버전으로 바꾸면 없어진 코드는 위 시·군·구, 시·도로 거슬러 올라가 보여 준다(`KoreaRegionCatalog.resolve`).

## 새 버전으로 바꾸기

1. 위 공공데이터포털 페이지의 참고문서 zip을 받아 격자_위경도 xlsx를 꺼낸다.
2. `python3 scripts/build-korea-regions.py <xlsx> > data/weather/src/main/assets/weather/korea_regions.csv`
   (새 시·도가 생기면 스크립트의 `SHORT_NAMES`에 짧은 이름을 더한다.)
3. `./gradlew :data:weather:testDebugUnitTest`로 목록 검사(`KoreaRegionDatasetTest`)를 돌린다.
4. 이 문서의 파일 이름, 날짜, sha256, 곳 수와 설정 › 정보 출처 문구의 날짜를 고친다.
