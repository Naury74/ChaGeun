# Play Data Safety 근거표

Play Console › 앱 콘텐츠 › 데이터 보안 양식을 채울 때의 근거다. 앱이 실제로 저장·전송하는 것과 개인정보처리방침(https://naurylab.com/chageun/privacy/), 설정 › 개인정보 및 데이터 안내 화면과 항상 맞아야 한다. SDK나 권한을 더하면 이 표부터 고친다.

## 수집하는 데이터

| Play 분류 | 항목 | 출처 | 목적 | 공유 | 필수 여부 |
|---|---|---|---|---|---|
| 개인 정보 | 이메일 주소 | Firebase Authentication(선택 계정) | 계정 관리 | 아니요 | 선택(계정을 만들 때만) |
| 개인 정보 | 사용자 ID(Firebase UID) | Firebase Authentication | 계정 관리 | 아니요 | 선택 |
| 앱 활동 | 앱 상호작용(“주유 기록 저장” 같은 이벤트, 기록 내용 없음) | Firebase Analytics | 분석 | 아니요 | 선택(설정 › 개인정보에서 끌 수 있음) |
| 앱 정보 및 성능 | 비정상 종료 로그, 진단 정보(기기 모델 등) | Firebase Crashlytics | 분석(안정성) | 아니요 | 선택(설정에서 끌 수 있음) |
| 기기 또는 기타 ID | 광고 ID | Google 모바일 광고 SDK | 광고, 사기 방지 | 예(Google 광고) | 동의(UMP)에 따름 |
| 기기 또는 기타 ID | Firebase 설치 ID | Analytics·Crashlytics | 분석 | 아니요 | 선택 |
| 위치 | 대략적인 위치(IP 기반) | Google 모바일 광고 SDK | 광고, 사기 방지 | 예 | **확인 필요**: AdMob 데이터 공개 가이드의 현재 권장값을 따른다 |
| 위치 | 대략적인 위치(기기 위치를 소수 첫째 자리, 약 10km로 반올림한 좌표) | 홈 날씨: `ACCESS_COARSE_LOCATION`(사용자가 날씨 카드에서 “현재 위치”를 고를 때만 요청) → MET Norway Locationforecast API | 앱 기능(날씨 맞춤 운전 팁) | **확인 필요**: 날씨를 받으려고 MET Norway(노르웨이 기상청)에 보내는 것이 Play의 “공유”인지. 차근은 좌표를 저장·로그하지 않고 요청 처리에만 쓰므로 “일시적 처리”로 볼 수 있는지 신고 전 확인 | 선택(날씨를 켜고 “현재 위치”를 고를 때만. 시·도를 직접 고르면 기기 위치를 쓰지 않음) |
| 파일 및 문서 / 사진 | 백업 파일(기록·사진·앨범 사진, 차량번호는 가린 값). 앨범 동영상은 크기 한도(200MB) 때문에 넣지 않는다 | 사용자 본인 Google 드라이브(appDataFolder) | 백업과 복원 | 아니요 | 선택(사용자가 켤 때만). **확인 필요**: 사용자 본인 드라이브로의 전송을 Play가 “수집”으로 보는지 신고 전 확인 |

## 수집하지 않는 데이터(기기 안에만 저장·처리)

- 차량 정보, 차량번호(Android Keystore 키로 암호화), 주행거리, 정비·주유·점검 기록, 메모, 첨부 사진·영수증, 내 차 사진·앨범
- 앨범 동영상: 앱 전용 저장소에 둔다. 가져올 때 다시 인코딩하지 않고 영상·소리 트랙만 새 MP4로 옮겨(MediaExtractor → MediaMuxer) GPS 위치(`©xyz`), 기기 정보, 위치·센서 기록 같은 시간 메타데이터 트랙을 남기지 않는다. 남는 것은 영상·소리, 회전 값, 파일을 만든 시각, MediaMuxer가 적는 Android 버전 표기(`com.android.version`)다. 사진 편집기(FrameKit, Media3 Transformer)로 고친 동영상은 원본 위치를 옮겨 적으므로 같은 과정을 거친다. 에뮬레이터에서 `©xyz` 위치를 넣은 MP4로 결과 파일에 위치가 남지 않음을 확인했다(2026-10-12). **확인 필요**: 실제 기기 카메라 원본(삼성·픽셀)으로도 결과 파일에 위치가 없는지 `exiftool`/`ffprobe`로 한 번 확인
- 데이터 내보내기(ZIP)에는 앨범 동영상이 들어간다. 파일을 하나씩 흘려 쓰므로 메모리를 많이 쓰지 않지만 ZIP이 커질 수 있다
- 내 차 사진 배경 제거와 계기판 주행거리 인식(ML Kit, 기기 안에서 처리, 사진 전송 없음)
- 외부 AI 공유: 사용자가 내용을 확인한 뒤 고른 앱으로 Android 공유 기능을 통해 직접 보낸다. 차근 서버를 거치지 않는다.
- 홈 날씨: 고른 위치(“현재 위치” 또는 시·도)만 기기에 저장하고 좌표는 저장하지 않는다. 받은 날씨는 메모리에만 두고 한 시간 안에는 다시 묻지 않는다. 시·도를 고르면 그 지역 대표 좌표만 보낸다.

## 보안 관행

- 전송 중 암호화: 예(Firebase, Google 드라이브, 광고 SDK, MET Norway 날씨 API 모두 HTTPS)
- 데이터 삭제 요청: 예. 앱 설정 › 계정에서 계정 삭제, 앱을 쓸 수 없으면 https://naurylab.com/chageun/delete-account/ (help@naurylab.com)
- 기기 데이터: 설정 › 데이터에서 내보내기·모두 삭제

## 그 밖의 콘솔 항목

- 광고 포함: 예(네이티브 광고, 안전 관련 화면·AI 화면·알림으로 들어온 화면 제외)
- 콘텐츠 등급: 설문 결과 전체 이용가 예상(사용자 간 소통·위치 공유·구매 없음). 대략적인 위치는 날씨 조회에만 쓰고 다른 사용자와 나누지 않는다
- 위치 권한: `ACCESS_COARSE_LOCATION`만 쓴다(정확한 위치·백그라운드 위치 없음). Play Console 권한 선언이 필요한지 **확인 필요**
- 출처 표시: 날씨 데이터는 MET Norway(CC BY 4.0). 홈 날씨 카드와 설정 › 정보 출처에 “날씨: MET Norway”를 적는다
- 대상 연령: 만 18세 이상 운전자. 아동 대상 아님
- 앱 액세스: 모든 기능을 계정 없이 쓸 수 있어 심사용 계정이 필요 없다
