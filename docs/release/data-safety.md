# Play Data Safety 근거표

Play Console › 앱 콘텐츠 › 데이터 보안 양식을 채울 때의 근거다. 앱이 실제로 저장·전송하는 것과 개인정보처리방침(https://naurylab.com/chageun/privacy/), 설정 › 개인정보 및 데이터 안내 화면과 항상 맞아야 한다. SDK나 권한을 더하면 이 표부터 고친다.

| 파일 및 문서 / 사진 | 백업 파일(기록·사진·앨범 사진·기록에 녹음한 소리, 차량번호는 가린 값). 앨범 동영상은 크기 한도(200MB) 때문에 넣지 않는다 | 사용자 본인 Google 드라이브(appDataFolder) | 백업과 복원 | 아니요 | 선택(사용자가 켤 때만). **확인 필요**: 사용자 본인 드라이브로의 전송을 Play가 “수집”으로 보는지 신고 전 확인 |

## 수집하지 않는 데이터(기기 안에만 저장·처리)

- 차량 정보, 차량번호(Android Keystore 키로 암호화), 주행거리, 정비·주유·점검 기록, 메모, 첨부 사진·영수증, 내 차 사진·앨범
- 앨범 동영상: 앱 전용 저장소에 둔다. 가져올 때 다시 인코딩하지 않고 영상·소리 트랙만 새 MP4로 옮겨(MediaExtractor → MediaMuxer) GPS 위치(`©xyz`), 기기 정보, 위치·센서 기록 같은 시간 메타데이터 트랙을 남기지 않는다. 남는 것은 영상·소리, 회전 값, 파일을 만든 시각, MediaMuxer가 적는 Android 버전 표기(`com.android.version`)다. 사진 편집기(FrameKit, Media3 Transformer)로 고친 동영상은 원본 위치를 옮겨 적으므로 같은 과정을 거친다. 에뮬레이터에서 `©xyz` 위치를 넣은 MP4로 결과 파일에 위치가 남지 않음을 확인했다(2026-10-12). **확인 필요**: 실제 기기 카메라 원본(삼성·픽셀)으로도 결과 파일에 위치가 없는지 `exiftool`/`ffprobe`로 한 번 확인
- 기록에 녹음한 소리: 앱 전용 저장소(`files/attachments/`)에 m4a로 둔다(한 기록에 5개, 하나에 3분까지). 마이크는 FrameKit 녹음 화면에서 녹음 버튼을 처음 누를 때만 권한을 묻고, 녹음하는 동안에만 쓴다. 녹음 화면이 남기는 녹음 파일(`files/framekit/recordings/`)과 편집기 결과 파일은 첨부로 옮긴 뒤 바로 지운다(다른 편집기가 이어 쓸 수 있는 7일 안의 녹음은 남기고 그보다 오래된 것은 다음 녹음 때 지운다). 소리는 사용자가 직접 내보낸 ZIP과 직접 켠 Google 드라이브 백업에만 들어가고, 외부 AI 질문에는 넣지 않는다. 설정 › 데이터 › 모두 삭제 때 녹음 파일과 함께 지운다. 파일 경로는 로그에 남기지 않는다
- 데이터 내보내기(ZIP)에는 앨범 동영상이 들어간다. 파일을 하나씩 흘려 쓰므로 메모리를 많이 쓰지 않지만 ZIP이 커질 수 있다
- 내 차 사진 배경 제거와 계기판 주행거리 인식(ML Kit, 기기 안에서 처리, 사진 전송 없음)
- 영수증 스캔과 영수증 PDF 글자 인식: FrameKit 문서 보정(모서리 찾기·반듯하게 펴기)과 ML Kit 한국어 글자 인식(`framekit-ocr`)을 기기 안에서 처리한다. 글자 인식은 앱과 분리된 `:framekit_ocr` 프로세스에서 돌고, 사진·인식한 글자를 서버로 보내지 않는다. 인식한 글자는 PDF 안의 보이지 않는 글자 층에만 들어가고 차근은 따로 저장·로그하지 않는다. 모델은 Play 서비스가 설치 때(또는 첫 사용 때) 받는다(`com.google.mlkit.vision.DEPENDENCIES`에 `ocr_korean`)
- 영수증 PDF 공유: 사용자가 기록 상세에서 "영수증 PDF로 공유"를 누르고 편집기에서 저장했을 때만 만들고, Android 공유 창으로 사용자가 고른 앱에 직접 보낸다. 차근 서버를 거치지 않는다. 편집기 결과 파일은 공유 파일로 옮긴 뒤 바로 지우고, 공유 파일(앱 캐시)은 하루 뒤 정리한다. 카드 번호·차량번호는 편집기의 가리기(모자이크·블러)로 지운 뒤 보낼 수 있다
- 외부 AI 공유: 사용자가 내용을 확인한 뒤 고른 앱으로 Android 공유 기능을 통해 직접 보낸다. 차근 서버를 거치지 않는다.
- Google 계정 이름·부를 이름·프로필 사진: 이름은 Firebase 계정 정보에서 그때그때 읽고 기기에 따로 저장하지 않는다. 부를 이름은 계정 화면에서 1~20자 한 줄로 정하며 Firebase 계정의 표시 이름에만 저장하고(다른 기기에서도 같음), 비우거나 “Google 이름 쓰기”를 누르면 지운다. Google로 다시 로그인해도 앱은 Google 이름으로 덮어쓰지 않는다. 계정을 삭제하면 Firebase 계정과 함께 지워진다. 사진은 앱 전용 저장소(`files/profile/`)에 한 장만 두고, 파일 이름은 사진 주소의 해시라 주소 자체는 남지 않는다. 로그아웃·계정 삭제·설정 › 데이터 › 모두 삭제 때 지운다. 이름·이메일·사진 주소는 로그에 남기지 않는다. 백업 파일에는 들어가지 않는다
- 홈 날씨: 고른 위치(“현재 위치” 또는 직접 고른 지역의 행정구역코드)만 기기에 저장하고 좌표는 저장하지 않는다. 받은 날씨는 메모리에만 두고 한 시간 안에는 다시 묻지 않는다.
- 홈 날씨 직접 고른 지역: 시·도, 시·군·구, 읍·면·동(행정동)까지 고를 수 있고, 그 지역의 대표 좌표(기상청 격자·위경도 자료, 앱에 내장)를 소수 둘째 자리(약 1km)로 반올림해 MET Norway에 보낸다. 기기 위치(약 10km 반올림)보다 좁지만, 사용자가 공개된 행정구역을 직접 고른 것이고 기기 위치와 무관하므로 “위치” 수집으로 보지 않는다(**확인 필요**: Play가 사용자가 고른 지역을 위치 데이터로 보는지 신고 전 확인). 지역 고르기 창에 보여 주려고 최근에 고른 지역 코드 5개를 DataStore에 두고, 설정 › 데이터 › 모두 삭제 때 지운다. 고른 지역과 좌표는 로그에 남기지 않는다.
- 홈 날씨 동네 이름: 찾은 동네 이름(시·군·구까지, 동·번지 없음)은 다음 실행 때 설정 › 날씨에 바로 보이도록 기기 DataStore에 둔다. 좌표는 저장하지 않는다. 날씨를 끄거나 위치를 바꾸거나 설정 › 데이터 › 모두 삭제하면 지운다. 동네 이름과 좌표는 로그에 남기지 않는다. 기기가 위치를 주지 못했을 때는 “찾지 못함” 표시(참·거짓 하나)만 같은 방식으로 두고 같은 때에 지운다.

## 보안 관행

- 전송 중 암호화: 예(Firebase, Google 드라이브, Google 프로필 사진, 광고 SDK, MET Norway 날씨 API 모두 HTTPS). 기기 지오코더의 전송 방식은 OS·Play 서비스가 정한다(**확인 필요**)
- 데이터 삭제 요청: 예. 앱 설정 › 계정에서 계정 삭제, 앱을 쓸 수 없으면 https://naurylab.com/chageun/delete-account/ (help@naurylab.com)
- 기기 데이터: 설정 › 데이터에서 내보내기·모두 삭제

## 그 밖의 콘솔 항목

- 광고 포함: 예(네이티브 광고, 안전 관련 화면·AI 화면·알림으로 들어온 화면 제외)
- 콘텐츠 등급: 설문 결과 전체 이용가 예상(사용자 간 소통·위치 공유·구매 없음). 대략적인 위치는 날씨 조회와 동네 이름 표시에만 쓰고 다른 사용자와 나누지 않는다
- 위치 권한: `ACCESS_COARSE_LOCATION`만 쓴다(정확한 위치·백그라운드 위치 없음). Play Console 권한 선언이 필요한지 **확인 필요**
- 마이크 권한: `RECORD_AUDIO`. 기록에 차 소리를 녹음할 때만 쓰고 백그라운드 녹음·포그라운드 서비스는 없다. 스토어 설명·개인정보처리방침에 마이크 사용 목적을 적어야 하는지 **확인 필요**
- 출처 표시: 날씨 데이터는 MET Norway(CC BY 4.0). 홈 날씨 카드와 설정 › 정보 출처에 “날씨: MET Norway”를 적는다. 지역 목록은 기상청 단기예보 격자·위경도 자료(공공데이터포털, 저작자표시)로 설정 › 정보 출처에 적는다(`docs/data-sources/korea-regions.md`)
- 대상 연령: 만 18세 이상 운전자. 아동 대상 아님
- 앱 액세스: 모든 기능을 계정 없이 쓸 수 있어 심사용 계정이 필요 없다
